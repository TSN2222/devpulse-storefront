# DevPulse Storefront

This project was created for **CSI-3150: Web and Mobile Systems** as part of Assignment 1B.

The purpose of this assignment is to translate a previously designed semantic architecture and user experience plan into a functional, responsive website using HTML5 and CSS3.

## Project Goals

The project focuses on practicing:

- Semantic HTML5 structure and document hierarchy
- Accessible navigation and form elements
- Native HTML5 form validation
- CSS Flexbox and Grid layouts
- Responsive design using media queries
- Interactive hover and focus states
- CSS custom properties and reusable design values
- Git version control and meaningful commit history

## Technical Requirements

The project is built using:

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Responsive Design

The interface is designed to adapt between desktop and mobile layouts. A responsive breakpoint is used to reorganize content for smaller screens while avoiding horizontal overflow.
